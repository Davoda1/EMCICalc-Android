The app, Qt libraries/plugins, TLS libraries and C++ runtime are supplied in the APK. GMP, MPFR, libxml2 and libqalculate are linked as PIC static libraries into the application. The source archives include their exact source archives and the build/port changes, enabling a modified app to be rebuilt. Android APK signature integrity applies: an in-place update requires the owner's retained signing key. These source archives contain no private signing material.

`third_party/android-source-manifest.json` records the exact dependency archive SHA-256 digests. `scripts/android-dependencies.sh` records the Android-only libqalculate thread portability patch and OpenSSL build configuration. `scripts/android-rebuild-qt.sh` rebuilds the target Qt libraries with both required page-size linker flags. The C++ runtime relinking/ABI verification scripts retain the official r27c compiler/runtime inputs rather than substituting a different NDK ABI. `scripts/android-toolchain-archives.json` and `scripts/android-qt-archives.json` pin tool downloads.

Android operating-system libraries, including system zlib, are provided by the device. Development SDK/NDK/JDK/Gradle tools are not installed as part of the application. NDK/LLVM notices are included separately under `third_party/licenses/`.

Currency data is obtained from the European Central Bank's public reference-rate feed when requested by the dedicated currency panel. User expressions and entered amounts are not included in requests. The app has no advertising, telemetry or account service.

## Navigation SVG assets

`assets/icons/arrow-left.svg` and `arrow-right.svg` are the Wikimedia Commons geometric triangle SVGs, authored by Sarang; the left file includes later styling by Antonsusi. The source pages designate both as public domain (PD-shape). Original SVG bytes, exact URLs, SHA-256 values and provenance are included in `assets/icons/NOTICE.txt` and `SOURCES.json`. The app draws the SVG path geometry with the selected theme’s foreground color.

## Android key click

`android/res/raw/emcicalc_key_click.wav` is an original deterministic PCM sound generated by `scripts/generate_android_key_click.py`, distributed under the application’s MIT license. It is not copied from Android or another calculator.
